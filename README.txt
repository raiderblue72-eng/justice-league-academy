JUSTICE LEAGUE ACADEMY — PERSONAL ANDROID WEB APP

WHAT'S INCLUDED
- Course catalog with starter links
- Add, edit, search, and filter courses
- Mark courses not started / in progress / completed
- Track study hours
- Specialist divisions
- Credential vault (records credential details; stores no certificate files)
- Rank progression and dashboard statistics
- Local data storage and JSON backup / restore
- Installable PWA manifest and offline service worker

COST
The app source is free. It has no subscription, analytics, ads, or app account. Course providers may have their own terms and credential fees; verify these before enrolling.

IMPORTANT INSTALL NOTE
For Android's installable-app experience, the files need to be served from a secure HTTPS address. You can host this folder free with GitHub Pages (public repository) or another static HTTPS host. Once hosted, open the site in Chrome on Android, tap the browser menu, then choose “Install app” or “Add to Home screen.” The exact wording varies by Android/Chrome version.

LOCAL PREVIEW
Open index.html in a browser to preview. Browser restrictions may prevent PWA installation and offline caching when opened as a local file.

PRIVACY / BACKUP
Course progress and profile details are stored in the browser's local storage on that device. They are not synced to a server. Use Personnel File > Export backup periodically. Clearing browser data can erase the app's saved records.

EDITING
Open index.html in a text editor to change the course seed list, colors, or features. Course data is initialized on first launch; resetting app data restores the starter list.

BRANDING

Android installation: use the HTTPS GitHub Pages URL in Chrome and choose Install app or Add to Home screen from the three-dot menu. See README-SHARED-ACADEMY.txt for deployment details.
